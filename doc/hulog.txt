1. 介绍                                            *hulog.nvim-introduction*

hulog.nvim 是 hulog 博客主题配色（暖纸 + 靛蓝 + 陶土橙）的 Neovim 配色。
项目结构参照 shaunsingh/nord.nvim（MIT）。

支持 Neovim 内置 LSP 诊断与 TreeSitter（TS* 与 @capture 双命名），
亮/暗双变体按 vim.o.background 自动切换。

插件支持：
  gitsigns / gitgutter、telescope、nvim-tree、which-key、nvim-cmp、
  indent-blankline（新旧命名）、nvim-notify、mini.nvim、dashboard、
  headlines、illuminate、leap / hop / flash / sneak、rainbow-delimiters、
  ts-rainbow、aerial、navic、nvim-dap(-ui)、neogit、lsp-trouble、noice、
  treesitter-context、bufferline、lualine

需求：Neovim >= 0.8（推荐 0.10+）。

2. 安装                                            *hulog.nvim-installation*

lazy.nvim: >
  { 'huzerovo/hulog.nvim', lazy = false, priority = 1000 }
<
packer.nvim: >
  use 'huzerovo/hulog.nvim'
<

==============================================================================
3. 使用                                                *hulog.nvim-usage*

启用配色： >
  colorscheme hulog
<
亮色模式（可选）： >
  vim.o.background = 'light'
  colorscheme hulog
<

lualine： >
  require('lualine').setup { options = { theme = 'hulog' } }
<

bufferline： >
  local highlights = require('hulog').bufferline.highlights({ italic = true, bold = true })
  require('bufferline').setup { options = { separator_style = 'thin' }, highlights = highlights }
<

headlines.nvim： >
  require('headlines').setup {
    markdown = {
      headline_highlights = { 'Headline1', ..., 'Headline6' },
      codeblock_highlight = 'CodeBlock',
      dash_highlight = 'Dash',
      quote_highlight = 'Quote',
    },
  }
<

==============================================================================
4. 配置                                          *hulog.nvim-configuration*

                                                       *hulog_contrast*
hulog_contrast        （默认 false）侧栏/浮窗使用 elevated 背景
                                                       *hulog_borders*
hulog_borders         （默认 false）显示垂直分割线
                                                   *hulog_disable_background*
hulog_disable_background （默认 false）不设置背景色，用终端背景
                                        *hulog_cursorline_transparent*
hulog_cursorline_transparent （默认 false）cursorline 背景透明
                                      *hulog_enable_sidebar_background*
hulog_enable_sidebar_background （默认 false）单独启用侧栏背景
                                                       *hulog_italic*
hulog_italic          （默认 true）斜体
                                                         *hulog_bold*
hulog_bold            （默认 true）粗体
                                          *hulog_uniform_diff_background*
hulog_uniform_diff_background （默认 false）diff 使用统一底色

示例： >
  vim.g.hulog_contrast = true
  vim.g.hulog_italic = false
  vim.g.hulog_uniform_diff_background = true
  colorscheme hulog
<
